# Running Coach (러닝 코치) 요구사항 정의서 (v2.0 MVP)

**작성일**: 2026년 8월 4일  
**버전**: v2.0  

---

## 1. 요구사항 목록

| 요구사항 ID | 기능명 | 세부 요구사항 내용 | 중요도 | 1차 MVP 포함 여부 |
| :--- | :--- | :--- | :--- | :--- |
| **REQ-AUTH-01** | 소셜 로그인 | 구글/네이버 OAuth2를 이용한 로그인 및 JWT 발급 | 필수 | **포함** |
| **REQ-AUTH-02** | 토큰 갱신 | Refresh Token을 이용한 Access Token 자동 연장 | 필수 | **포함** |
| **REQ-DASH-01** | 누적 실적 요약 | 이번 달 총 달린 거리, 횟수, 평균 페이스 카드 제공 | 필수 | **포함** |
| **REQ-DASH-02** | 최근 기록 리스트 | 최근 작성한 러닝 기록 5건을 카드 형태로 노출 | 필수 | **포함** |
| **REQ-DASH-03** | 주간 차트 시각화 | 최근 7일간 일별 주행 거리 막대 그래프 시각화 | 필수 | **포함** |
| **REQ-RUN-01** | 러닝 기록 등록 | 날짜, 거리(km), 시간(분/초), 훈련유형, 심박, RPE, 메모 등록 | 필수 | **포함** |
| **REQ-RUN-02** | 러닝 기록 목록 | 러닝 기록 목록 페이징 및 월별 필터링 기능 제공 | 필수 | **포함** |
| **REQ-RUN-03** | 러닝 기록 상세 | 선택한 러닝 기록의 세부 항목 조회 | 필수 | **포함** |
| **REQ-RUN-04** | 러닝 기록 수정/삭제| 기존 등록된 러닝 기록 항목 수정 및 삭제 | 필수 | **포함** |
| **REQ-STAT-01** | 월별 통계 분석 | 월별 누적 거리 및 이동 시간 추이 차트 제공 (FastAPI 연동) | 필수 | **포함** |
| **REQ-STAT-02** | 페이스 추이 분석 | 월별 평균 페이스 변화 그래프 시각화 | 필수 | **포함** |
| **REQ-GOAL-01** | 목표 설정 | 주간/월간 목표 거리 설정 | 보통 | **제외 (2차)** |
| **REQ-GOAL-02** | 목표 달성률 계산 | 러닝 기록 등록 시 목표 달성률 자동 업데이트 | 보통 | **제외 (2차)** |
| **REQ-RACE-01** | 대회 기록 등록 | 대회명, 개최일, 종목, 완주기록 및 완주증 사진 등록 | 선택 | **제외 (2차)** |
| **REQ-RACE-02** | 대회 기록 목록 | 참가한 대회 기록 이력 조회 | 선택 | **제외 (2차)** |
